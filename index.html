Engineering Decisions
⚡Event-driven architecture to reduce coupling — dispatch, lifecycle, and notifications are fully independent
🔁Chose eventual consistency over strong consistency to allow horizontal scaling of the dispatch engine
📡WebSockets instead of polling — instant driver notifications, no constant HTTP overhead
🗂Modular Spring Boot services — each domain (ride, driver, dispatch) owns its own boundary
Challenges Solved
⚠️Handling race conditions in driver assignment when multiple riders request simultaneously
🔀Managing real-time state across multiple services without a central bottleneck
🔒Ensuring system consistency under concurrent requests while keeping latency low
📶Maintaining WebSocket connections gracefully across network interruptions on mobile
